2.5E DANMAKU · READABILITY PROTOTYPE v0.7

平面移动，立体弹幕

你被限制在地面这一个平面上，但弹幕在真实的三维空间里飞行：贴地扫射、高空压制、环形扩散、旋转激光、墙缝推进。 这个装置不做美术、不做养成，只验证一件事 —— 玩家能不能读懂“子弹在哪里”。
两种视角模式： 自由视角 —— PC 上点一下画面锁定鼠标，之后移动鼠标就是转视角（和常规第三人称一致，ESC 解锁、滚轮拉远近）；手机右半屏搓动，或用 Q E。 极坐标模式（按 V / 手机「极轴」键）—— 以场地中心为原点，摇杆上下 = 沿半径进出，左右 = 绕中心改变角度，镜头永远沿径向朝中心；此时相机锁死朝中心，鼠标只调俯仰、横移无效。 想验证“极坐标操作是否比自由移动更不容易迷失方向”，就用这两种模式交替打同一个 boss。

16 种弹幕图案 · 多发射源 地面投影 + 弹幕拖尾 自由视角 + 极坐标模式 俯视雷达（颜色=高度） 受击诊断日志
COLOR = HEIGHT 颜色是一条连续的彩虹：红=贴地（要起跳）→ 橙 → 黄 → 绿 → 青 → 蓝 → 紫=12m 高空（别跳，从下方穿过）。颜色只跟“这一刻的高度”走，所以同一颗弹从高空落下来会一路变色 —— 你读到的永远是它现在在哪一层，而不是它出生时的标签。
地面亮圈 = 即将落下的东西：俯冲弹会先悬停再砸、地雷会读秒后向四周炸开一圈低空弹、地涌会从地底竖直升起 —— 都靠“离开圈”躲。
READ AIDS T 切换轨迹线：默认是拖尾（跟在弹后面的实线，颜色同弹、按真实高度画，能看出它从哪来）／第二档是预测虚线（弹头往前 0.5 秒）。 M 切换左上角俯视雷达：从上方看整片战局，弹幕颜色 = 高度（实心=贴地/要跳，空心紫=高空/别跳）。
TEST GOAL 玩 3 局，每局结束后回答：每次被击中时，你是否知道“为什么被打中”？如果三次里有一次说不清，可读性系统就不合格。
