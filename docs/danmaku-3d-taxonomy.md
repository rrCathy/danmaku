# 3D 弹幕分类学（Taxonomy of 3D Danmaku）

> **定位**：分类学主文档。前篇 `danmaku-framework.md`（五层语法——图案怎么**构成**）与 `danmaku-math.md`（数学词源——图案怎么**生成**）回答的是构建问题；本文回答**存在**问题：3D 弹幕这个设计空间里到底**有哪些物种**、它们与 2D 的本质区别在哪、当时的 39 图案在分类上处于什么位置。
>
> **方法**：不沿用 2D 五维（瞄准/几何/轨迹/节奏/视觉）做 3D 扩写——那会把 3D 误当成"多了个 z 轴的 2D"。正确起点是 3D 弹幕的第一性事实：**玩家流形与弹空间的维数不匹配**。一切分类轴由此推出。

---

## 0. 元层：3D 弹幕的形态学（先分类"游戏"，再分类"弹"）

弹幕分类的前提是玩法配置。核心参数：**玩家流形维数 vs 弹空间维数之差**。

| 玩家流形 | 有效维数 | 弹空间 | 维数差 | 例 | 深度可读性问题 |
|---|---|---|---|---|---|
| 同一平面 | 2 = 2 | 2D | 0 | 东方等 2D STG | 无——判定关系即所见关系 |
| **实心圆柱（盘 × 海拔 0~3.0m）** | **2.5D（预算制）** | **3D** | **+0.5** | **本项目** | 高度歧义——同一屏幕点对应一条视线上无数位置 |
| 球面 | 2 | 3D | +1 | Super Stardust HD | 同上 + 极区畸变 |
| 圆筒线 | 1 | 3D | +2 | Tempest | 已被约束消除 |
| 自由飞行 | 3 = 3 | 3D | 0 | Star Fox 全向模式 | 无维差，但自由度太大导致密集弹幕不可读 |

**四条形态学定律**（v2 按二段跳修正）：
1. **维数差 = 可读性税**。每差 1 维，就必须有显式读通道补偿（本项目：颜色=高度）。
2. **成功案例全部把玩家约束到低维流形**（圆柱/球面/圆筒）——自由 3D 从未支撑过密集弹幕。
3. **跳不是二值开关，是预算制自由度**：二段跳冲量 [9.4, 8.6]、g=27 → 玩家海拔可编程 [0, 3.0m]、无悬停、重力强制回收。可达域是**实心圆柱**（盘 × [0,3.0]）；"跳/不跳"语法随之升级为"**花多少跳预算、何时花**"（详见 §11）。
4. **控制自由度记账**：平面 2（连续）+ 垂直预算 0.5（2 冲量 + 时机）= **2.5D**；若删去跳：平面 2 + 身体高度 0.25（胶囊有高但不可控）= 2.25D——高度**感知**仍在（判定窗），只是**控制**没了。

> 本项目定位：**实心圆柱可达域 × 固定斜相机 × 高度=唯一新增自由度（预算制）**。下文全部分类轴以此为语境，但结构对球面/圆筒版本同样成立（换流形即可）。

## 1. 第一分类轴：威胁几何（2D 不需要的轴）

**定义**：玩家可达时空域 P = { (x, z, y, t) } —— (x,z) 在圆盘内，y ∈ 站立带 ∪ 跳跃带（站立 0.44~1.16m，跳起 2.08~2.80m，见框架文档 §2.2）。每颗弹的世界线 B(t) 与 P 的**交集结构**决定它的威胁类型。

**关键澄清**：威胁类型不是弹的固有属性，是**"弹 × 玩家行为"的二元关系**——同一颗 `sweepHigh`，对站着的人是"无危"，对跳起的人是"命中"。因此：

> **图案 = 对玩家行为空间的一个划分。** 设计图案，就是在选择"哪种行为落入哪类威胁"。这是"跳/不跳"语法的严格化。

| 威胁类 | 交集结构 | 玩家语法 | 已有图案 |
|---|---|---|---|
| **恒在**（面内） | 世界线段落全程落在可达带内 | 2D 语法全适用：横移、穿缝、绕行 | `wall`、`gate`、`random`、`sniper` |
| **临界**（掠面） | 贴着可达带的边界走（站立带顶/跳跃弧顶） | 跳 or 不跳 + 时机；**边距**（弹缘到跳跃弧的距离）=难度旋钮 | `sweepLow`、`sweepHigh`、`sweepLine`、`gaster`、`toho` 高臂、`stack` 高钉 |
| **穿行**（跨面） | 世界线在可计算的时空点单次穿越可达带 | 事件规避：读标记，不在事件点 | `rain`、`downpour`、`lightning`、`rise`、`uprain` |
| **转入**（变轨） | 从带外转入带内（变向/引爆/坠落） | 读转变征兆，转变前脱离 | `dive`、`feint`、`mine` 引爆、`risenare` |
| **无危**（面外） | 无交集 | 气氛弹、假威胁——**必须作为独立类别管理**，否则可读性负载失控 | `sweepHigh` 之于站立者、飞行高度装饰弹 |

**无危类是 3D 特有的管理难题**：2D 里几乎所有可见弹都是真威胁（注意力可以全部给弹）；3D 里画面上大量弹是气氛——**分类学必须区分"压力弹"与"致死弹"，且让玩家能一眼区分**，否则"说不清为什么被打中"的根源正是把气氛弹当了真、或把真弹当了气氛。`feint`（紫色骗高度）就是对这条边界的**故意攻击**——它是 L2 的原因也就清楚了：教完颜色=高度，立刻教"颜色也会骗你，要看转变"。

## 2. 第二分类轴：高度剖面（3D 的第一运动学轴）

2D 分类里 y 只是另一条屏幕轴；在地面锁定语境下，高度是**既是躲避维度又是读数维度**的双重身份，升级为独立分类轴。

**剖面词汇**（单弹/单层的 y(t) 形状）：

| 剖面 | 形状 | 已有 |
|---|---|---|
| 定高 | y = 常数 | 多数（锚带表选位） |
| 阶梯 | 分段定高递变 | `stair`、`aimed` 三档 |
| 单调升降 | y 单调 | `rise`、`uprain`、`rain` |
| 振荡 | 正弦摆动 | `spiral`、`counterSpiral` |
| 场驱动 | y = f(位置, t)，与单弹速度无关 | `wave`、`ripple` |
| 弹道 | 重力抛物线 | `fountain`、`grenade` |
| 悬停-突变 | 两段式，转折点即威胁 | `dive`、`feint` |

**层间关系词汇**（多带图案的结构，弹与弹之间的关系而非弹自身的运动）：

| 关系 | 结构 | 已有 |
|---|---|---|
| 同步 | 各带同时到达 | `wall` 三层 |
| 相位交错 | 固定相位差 | `wave` 三排 2π/3、`counterSpiral` π/2 |
| 奇偶交替 | 逐臂/逐层低高交替 | `toho`、`pinwheel`、`radial` |
| 独立随机 | 无结构 | `spread`、`random` |
| 高度钉扎 | 主体低带 + 稀疏高带惩罚 | `stack` 高钉 |

> 晶体学视角（数学文档 §3）：层间关系就是图案的**格点结构**；"奇偶交替"= 双色子格，"相位交错"= 平移群作用。

## 3. 第三分类轴：排列 = 载面 × 原语 × 取向

2D 三原语（spread/ring/stack，Sparen 记法）在 3D 的正确推广不是加形状名词，而是**给原语指定一个承载曲面（载面）**：原语在载面上展开，载面在空间中取向，且载面自身可以运动（运动轨迹 = 时空中扫出的 worldsheet，见 §9 场类）。

**载面 × 原语矩阵**（✓=已有图案，空=空白即 backlog）：

| 载面（2D 流形） | ring | spread | stack |
|---|---|---|---|
| 水平面 | ✓ `ring`/`toho`/`ripple` | ✓ `petal`/`radial` | ✓ `stack` 同心层 |
| 竖直面（法向朝玩家） | — 帘环 | — **帘**（backlog 首位） | ✓ `wall`/`jumpWall`/`gate`/`wave` |
| 斜面 | — | — | — |
| 柱面（轴竖直） | — 收缩圆幕 | —（`spiral` 近似：柱面螺线） | — |
| 球面（心=爆点） | — 球面环 | ✓ `grenade` 上半球 | — 球壳层 |
| 锥面 | — | ✓ `cone` | — |
| 螺旋面 | — 螺升梯 | — | — |
| 无载面（场） | ✓ `ripple` 节构 | ✓ `downpour` | ✓ `wave` 三排 |

**用法**：新图案 = 从空格里挑格子，先问"它的解法动词和堵路是什么"（框架文档 §3.5 登记表），再实现。矩阵同时说明：**已有图案集中在"水平面 + 竖直面"两行**——载面维度的探索率很低，这就是 backlog 的系统性来源（与数学文档 §8 梯队一致）。

**2026-11 补充：点阵（lattice）作为第三类排列。** 上面矩阵里的原语都是"在某个载面上摆点"，但**点阵本身**可以是一种排列——把空间群/点群/格点直接当生成器：面心立方的 (001) 层状堆垛（ABAB）、螺旋轴（自转 + 升降）、空位与位错这类晶格缺陷。这类图案的运动不再是逐弹的运动学，而是**整片晶体当刚体走**（群变换：平移 / 自转 / 缩放），引擎层面由 `Bullet.lg` 共享组帧承载。

> **2026-11 修订（v4）**：同批删除 `ripple` 波纹，全项目 **39 → 41 招**；纯度分布 **3D 本质 30 / 2.5D 7 / 2D 本质 4**。
> 晶格系经三轮实测反馈重做：v1/v2（两档高度 + 沿推进方向成排）本质是"跃墙加点阵纹理"；v3 的 (001) 层状晶体运动仍限于水平面，被实测判为"本质平面弹幕 + 一圈圈安定点"——病根是**运动方向只有原地转和贴地平移**。
> **v4 = 晶体沿体对角线 (1,1,1) 移动**：FCC 的 (111) 密排面（三角堆积）垂直于运动方向，逐层斜着扫过玩家高度带；且 **ABC 堆垛让任何地面位置恰好被三层中的恰好一层覆盖** → 结构性 0 安定点（堆垛保证，不是调参）。可复用结论：**运动方向决定玩家读到的维度**——平面运动只能做出平面弹幕；威胁要来自"整层面扫过"而不是"散点可钻"；密排面网眼（最近邻 2.4m，空位净空约 1.2m）刚好容下玩家。

## 4. 第四分类轴：源的维数与锚定

2D 的源基本只有点（敌机）与屏幕外；3D 的源有**维数**：

| 源维数 | 几何 | 已有 |
|---|---|---|
| 0（点） | boss、炮口、爆点 | 多数、`gaster`、`mine` |
| 1（线） | 直线发射器 | —（backlog：沿线扫射） |
| 2（面） | 天花板/地面整体 | `downpour`（全场顶面采样）、`uprain`（地面底面） |
| 3（体） | 体积内随机 | —（backlog：与蓝噪采样配合，见数学文档 §6） |

另两个独立参数（v1.20 判据的推广）：**锚定**（场地锚 vs 玩家锚——环境级以场地为参照，追人型以玩家为参照）与**可见性**（源可见→读源；源不可见→必须给标记，见 §7）。

## 5. 第五分类轴：瞄准语义（3D 扩展）

2D 瞄准词汇（无瞄/自机狙/预判狙/锁定狙/偏移瞄）全部继承，3D 新增四种：

| 3D 新瞄准 | 语义 | 解法含义 |
|---|---|---|
| **高度分离瞄准** | 水平瞄你、高度选带——"瞄你不打你" | 瞄准信息不再等于威胁信息；必须加读高度 |
| **堵路狙** | 打向玩家"不得不去"的位置（缺口、唯一生路） | 惩罚已学会的解法——L2"堵路"设计法的瞄准版 |
| **会猎狙** | 多源向预判会合点收拢 | 必须识别两个以上的源并找不动的点 |
| **立体角封锁** | 锥/半球覆盖一块立体角 | 径向思维：离开锥或贴锥边，而非平面绕行 |

现有对照：`aimed`/`sniper` = 预判狙；`cone` = 立体角封锁雏形；高度分离瞄准已隐含在 `fanShot`（瞄玩家、高度另定）但**未作为独立欺骗手段使用**——backlog。

## 6. 第六分类轴：解法签名（图案的指纹）

把框架文档的解法动词表升级为**签名**：一个图案的解法签名 = (动词多重集, 禁忌动词, 时序结构)。

| 签名类型 | 结构 | 例 |
|---|---|---|
| 单动词 | 一个动作重复 | `sweepLow` {跳} |
| 禁忌型 | 关键是**不做**某动作 | `sweepHigh` {忌跳}、`stack` 高钉段 |
| 节律链 | 动词按时间排布 | `jumpWall` [{跳},{忌跳},{跳}]、`aimed` {微移}×4 |
| 同时双动词 | 两动词并行 | `risenare` {离圈∧横移}、`grenade` {离圈∧择时} |
| 关系型 | 动作对象是结构而非弹 | `pinwheel`/`counterSpiral` {跟缝}、`ripple` {等谷} |

**签名的两个用途**：
1. **训练聚类**：同签名不同几何 = "同课不同形"——`sweepLow`/`sweepLine`/`gaster` 共享 {跳} 签名，是同一课的三种几何变体。**训练场应按签名分组排序**，检验的是"解法迁移"而非"图案记忆"——这正是验收命题（可读性=能读出解法）的直接测试。
2. **难度审计**：禁忌型与同时双动词是 3D 特有的高认知负载类型，其分布应随难度递进（现有：禁忌型 L1 起有 `sweepHigh`，节律链 L2 起，符合递进）。

## 7. 第七分类轴：读通道（深度消歧方式）

框架文档列了通道清单（颜色/圈/源/形状/雷达），分类学关心的是**消歧机制**的类型：

| 机制 | 原理 | 已有 |
|---|---|---|
| 静态编码 | 颜色=高度，逐帧映射 | 全局主通道 |
| 事件标记 | 把"将要发生的事件"画在玩家流形上（地面圈） | `rain`/`lightning`/`mine` |
| 源锚 | 可见发射体 | `gaster` 炮口、`laser` warm |
| 参照物 | 场地线、格子、boss 高度 | 环境级图案依赖 |
| 动态视差 | 靠相对运动消歧 | 隐式（未作为设计手段） |
| 形状语义 | 弹形=行为类别 | `arrow`/`box`/`octa` |

> `feint` 的设计意义在此显形：它攻击的是"静态编码"通道的可信度，逼玩家升级到"动态视差 + 转变征兆"——**读通道的攻击与升级**本身是可分类的设计动作。

## 8. 审计：39 图案的 3D 纯度

**判据**：
- **2D 本质**：把高度压平（所有弹降到同一平面）后，解法不变；
- **2.5D**：高度参与"读"（颜色分辨负担）但不改变解法动词；
- **3D 本质**：解法本身是垂直动作、高度选择或事件规避——压平后图案不成立。

| 档 | 数量 | 图案 |
|---|---|---|
| **3D 本质** | 28 | `sweepLow` `sweepHigh` `spread` `stair` `rise` `lowHigh` `dive` `rain` `mine` `laser` `satBurst` `jumpWall` `risenare` `feint` `downpour` `fountain` `uprain` `cone` `aimed` `smoke` `lightning` `grenade` `wave` `ripple` `sweepLine` `gaster` `toho` `stack` |
| **2.5D** | 7 | `ring` `spiral` `counterSpiral` `orbit` `petal` `radial` `pinwheel` |
| **2D 本质** | 4 | `wall` `sniper` `gate` `random` |

（边界案：`ring` 若各层同步到达则升为 3D 本质；`cone` 取立体角封锁解读为 3D 本质。）

**发现**：
1. 图案库整体已是 3D 主导（28/39），命题成立；
2. **2D 本质图案集中在 L1/L2**（`wall`/`sniper`/`gate`）——难度曲线实际上是**维度增益曲线**：先教平面生存，再加高度语义；
3. **L3（形状微操）是 2.5D 密集区**（`petal`/`radial`/`spiral`/`pinwheel` 全在此档）——它练的是平面结构阅读，高度只是纹理。这意味着 L3 与"读高度"命题关联最弱，若实测发现 L3 教学价值低，方向应是给形状类加层间关系（§2），而非加密度；
4. 7 个 2.5D 图案是"免费的 3D 化候选"：给它们加高度剖面变化或层间关系，即可以小改动升维（如 `pinwheel` 臂高做行波、`ring` 层间做相位差）。

## 9. 物种图鉴：3D 特有、2D 无类比的七类

| # | 物种 | 定义 | 2D 对应 | 已有 | 空白候选（载面矩阵空格） |
|---|---|---|---|---|---|
| 1 | **穿面类** | 威胁是可计算的时空**事件**而非持续物体 | 无（2D 雨弹仍是同面运动） | `rain`/`rise`/`lightning`/`uprain` | 面源体积雨、会猎穿面 |
| 2 | **临界类** | 弹贴可达边界，跳/不跳+边距 | 无（无可达边界概念） | `sweepLow/High`/`toho`/`stack` | 斜面临界（斜环扫掠，边距连续可调） |
| 3 | **场类** | 弹是场的采样，玩家跟踪的是**节构**（节点/波谷）而非弹 | 无 | `wave`/`ripple` | 振盘模态、驻波安全环（数学文档 §4） |
| 4 | **层间类** | 威胁在层与层的**关系**里（相位/奇偶/钉扎） | 弱（2D 密度节奏近似） | `toho`/`wave`/`stack` | 相位帘、奇偶球壳 |
| 5 | **立体角类** | 从爆心出发的立体角封锁 | 无（2D 角=平面角） | `grenade`/`cone` | 球壳带孔（极点孔安全）、Fibonacci 均匀爆 |
| 6 | **包围类** | 安全区被拓扑割断（环闭合/网收拢），生存=留在连通分量内 | 弱（2D 环无高度逃逸） | `ring`/`stack`/`mine` 爆环 | 收缩圆幕（柱面 net） |
| 7 | **气氛类** | 无危弹制造的压迫/装饰 | 无（2D 全是真威胁） | `sweepHigh`（对站立者） | 显式气氛层——须与真威胁有可读区别 |

> **气氛类要单独强调**：3D 弹幕的可读性预算里最贵的一项是"玩家区分真假的成本"。分类学建议：气氛弹应有独立的、可一眼识别的编码（如去饱和/固定单色——不参与高度彩虹），把"颜色=高度"通道**完全让给真威胁**。当前 `sweepHigh` 复用同一彩虹编码，是可读性负载的一个隐患点（与 HANDOVER §8 #4"落点雨失专属色"同根：编码通道被非威胁信息占用）。

## 10. 难度语法：3D 的难度由什么构成

2D 难度 ≈ 密度 × 弹速 × 组合复杂度。3D 在此之上**乘**一个垂直项：

| 3D 难度因子 | 含义 | 度量 |
|---|---|---|
| **带宽比** | 威胁带厚度 vs 玩家可调高度 | 弹径/跳跃可调高度（当前 ~0.42/1.6） |
| **边距** | 临界弹缘到跳跃弧的距离 | 越小越难（当前锚带 0.55/2.45 的边距是"宽容"设定） |
| **层间可读性** | 多带关系的可学习程度 | 相位差是否恒定、奇偶是否规则 |
| **深度线索强度** | 主读通道的信息量 | 通道数 × 每通道可靠性（`feint` 主动降它） |
| **注意目标级别** | 玩家注意的对象：弹(点)→结构(线/环)→源(点)→节律(时间) | 级别越高认知负载越大（`pinwheel` 跟结构 > `aimed` 跟弹） |

> 注意目标级别是认知层分类：它解释了为什么 `pinwheel`（弹不多）比 `random`（弹多）更难——**跟结构比躲弹耗工作记忆**。调参时密度只是最粗的旋钮。

## 11. 垂直维度的精确模型（v2：二段跳修正）

### 11.1 海拔 = 预算制自由度

- 2 个冲量 [9.4, 8.6]，海拔可编程 [0, 3.01m]，无悬停；
- **垂直棘轮**：上升慢（减速段可被打）、下落快（g=27，不可取消）——躲避性上升昂贵，回落是强制的 → "**攻击落地窗口**"（逼玩家烧完预算，在其下落段收网）是 3D 特有的序列层武器；
- 预算管理本身成为解法：**留跳**（把第二跳留给下一拍）= 移动版的资源经济（弩虚镰宝石的同构物）。

### 11.2 危险窗与越顶（取代二值锚带，推导见框架文档 §2.2 v2）

- 命中条件 = 玩家海拔落入 (h_b−1.37, h_b−0.23)，窗宽恒 1.14m；
- 越顶上限：单跳 < 1.87m、双跳 < 3.24m；
- **单跳陷阱带** 1.87~3.24：站立与双跳越顶皆安全，唯独单跳死——`sweepHigh` 的语义精确化为"**惩罚单跳**"，双跳越顶是未教授的进阶解（教学机会）；
- 新解法动词：**越顶**（单/双）、**留跳**、**穿窗**。

### 11.3 三段天（按玩家可达性给高度分层）

| 层 | 高度 | 玩家关系 |
|---|---|---|
| 可控天 | 0 ~ 3.0 | 预算内可入可离 |
| 强制穿越 | 3.0 ~ 4.2（胶囊顶） | 只能路过，不可驻留 |
| 天外 | > 4.2 | 永不可达——**纯源实体**（boss 悬停 5.4）；天外弹的威胁 100% 是穿行事件，读通道完全依赖 telegraph |

### 11.4 垂直节律与跨招残留

滞空 0.70s（单跳）/ 1.14s（双跳）vs 出招间隔 1.85 / 1.42 / 1.12 / 1.02 → **L3 起 cd < 双跳滞空**，L4 明显重叠：垂直状态（空中与否、剩余跳预算）会带进下一招。序列层新词汇：**垂直衔接**——前一招收尾时的海拔状态决定后一招的解法难度。

### 11.5 资源税向量（与解法签名 §6 互补）

每个图案对四项资源征税：{平面位移需求, 跳预算(0/1/2), 冲刺冷却(1.15s), 注意目标级别(§10)}。**签名 = 必须做什么；税 = 要花什么。** 例：`jumpWall` 征跳×3；`sweepHigh` 征"克制"（负税）；`stack` 征跳+忌跳节律。堵路设计（HANDOVER §7.2）与资源经济在此统一：堵路 = 强制征税，资源见底 = 被迫走进下一招的陷阱。

### 11.6 垂直穿窗（帘/夹层类的难度旋钮）

横穿水平弹层的可行条件：**空间缝**（层心距 ≥ 1.14m = 胶囊 0.72 + 双弹径 0.42）或**时间缝**（层到达间隔 ≥ 越层滞空段）；穿窗时长 ≈ (缝宽 − 0.72) / 下落速度。这给"帘/斜环/夹层"物种一个从"不可能"到"宽裕"连续可调的精确难度公式。

### 11.7 状态狙（3D 原生瞄准逻辑）

瞄准目标从位置 (x,z,y) 升级为**状态** (x,z,y,ẏ)：**反应式重力**——弹在玩家起跳/下落时才启动下落或匹配下落速度，直接中和垂直躲避（`feint` 的垂直版）。触发于玩家状态、由输入驱动，确定性不受影响（输入属于状态的一部分）。

### 11.8 对读：基本认知动作

地面锁定 3D 弹幕中，玩家持续执行的是**体积威胁 ↔ 流形标记的二维-三维对应**（弹在空中、记号在地上）。标记语法：点（读秒圈）/ 线（束的地面投影）/ 面（区域染色）；难度旋钮 = 标记与实体的视差偏移随时间的变化率。§7 读通道应统一在"标记语法"下描述。

### 11.9 可选第四通道与待验证

- 音高=高度：WebAudio 纯合成、零资产——潜在读通道（暂缓：先保"纯几何也能读"命题纯净）；
- 待验证（动模型前先测）：①冲刺能否空中使用 ②空中水平控制是否全额 ③二段跳触发窗（是否限上升段）。三项结论都会改动 11.1 的预算模型。
