# 2.5E 弹幕 · 三维可读性验证装置

把玩家锁在地面一个平面上，让子弹在真正的三维空间里飞，然后回答一个问题：

> **玩家能不能读懂「那颗弹现在在哪一层」？**

这不是一个弹幕游戏。没有美术、没有养成、没有剧情，只有 16 种弹幕图案、一套高度视觉编码、一套受击诊断。
凡是「好玩」但「看不懂」的东西，优先级都排在后面。

- 当前版本：**v0.7**（Vite + TypeScript，零运行时依赖）
- 交接文档：**[HANDOVER.md](./HANDOVER.md)**（模块地图、数值表、图案清单、已知问题、路线图）
- 历史基线：`archive/v0.6-single-file.html`（重构前的单文件版本，1:1 对照用）

## 这个项目是干什么的

三条研究线，各自对应代码里的入口：

| 研究目的 | 怎么用 | 从哪里改 |
|---|---|---|
| **测试玩法** | 直接打，看能不能读懂、躲不躲得开 | `src/config.ts`（所有数值） |
| **研究机制** | 单独跑某个图案、固定种子复现、dump 快照对比 | `src/patterns/`、`?pat=` `?dbg=1` |
| **玩家验证** | 3 局 × 受击诊断 + 结算页的受击分布 | `src/ui/diag.ts`、`src/systems/bullets.ts` |

验收线（原型的判断标准，不是感觉）：

> 玩 3 局，每局结束后问：**每次被击中时，你是否知道「为什么被打中」？**
> 三次里只要有一次说不清，可读性系统就不合格。

## 视觉编码

### 颜色 = 当前高度（连续）

| 高度 | 0 m | 0.9 | 1.8 | 3.0 | 4.6 | 7.6 | 12 m |
|---|---|---|---|---|---|---|---|
| 颜色 | 红 | 橙 | 黄 | 绿 | 青 | 蓝 | 紫 |
| 怎么躲 | 起跳 | 侧走 | 侧走 | — | 别起跳 | 从下方穿 | 从下方穿 |

颜色只由**这一刻的高度**决定，所以一颗弹从高空落下来会一路变色（紫→蓝→青→黄→红）。
你读到的永远是它现在在第几层，而不是它出生时贴的标签。

### 其它读 Aid

- **地面亮圈**：即将落下的东西（俯冲弹悬停读秒 / 地雷读秒 / 地涌升起），靠「离开圈」躲
- **俯视雷达**（`M`）：颜色同样 = 高度，**实心 = 低空，空心 = 高空**
- **轨迹线**（`T`）：拖尾 / 预测虚线 / 关
- **受击诊断**：每次被打中记录「被什么打中 / 命中高度 / 怎么躲」，只留最近 4 条（`config.ts: DIAG_KEEP`）

## 调试 / 自动化参数

URL 上直接带，适合做可复现的验证：

| 参数 | 作用 |
|---|---|
| `?auto=1` | 直接开打，跳过说明页 |
| `?dbg=1` | 把 `cam / player / boss / bullets / clock / counts / kinds / run() / dash()` 挂到 `window.__dbg` |
| `?pat=rain` | 开局触发指定图案（16 种全支持：`sweepLow` `sweepHigh` `spread` `ring` `stair` `rise` `lowHigh` `dive` `rain` `mine` `laser` `wall` `spiral` `counterSpiral` `satBurst` `orbit`） |
| `?t=30` | 无渲染快进 30 秒（同步执行，可用于逐位对照） |
| `?drive=wasd` | 模拟按住移动键 |
| `?fire=1` | 模拟一直开火 |
| `?boss=200` | 直接把 boss 血量设成 200（测 P2 / P3 的图案池） |
| `?polar=1` | 直接进极坐标模式 |
| `?cam=2` / `?yaw=1.2` | 指定镜头预设 / 环绕角度 |
| `?touch=1` | 强制走触屏布局（桌面调试手机端） |

`?auto=1&dbg=1&pat=mine&t=14` 这一串就够复现「地雷图案下前 14 秒的全部状态」。
